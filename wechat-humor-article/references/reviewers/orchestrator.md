# 多评审总编排与自动重写

只负责调度、汇总、去重、生成修改清单和控制重写次数，不直接创作正文。

## 加载模块

- `fact-risk.md`
- `originality.md`
- `reader-attraction.md`
- 根级 Skill `toutiao-article-auditor`（正式今日头条唯一 AI 痕迹审核）
- `platform-growth.md`

## 调度顺序

0. 今日头条任务先加载 `toutiao-dual-account-positioning.md`，确认 `target_account`、固定栏目和跨账号重复检查；写作端先将用户多个观点归并为一个核心判断和素材池，不按用户列举顺序生成目录。其他评审接收该稿的5个标题选项、推荐标题、正文、素材依据、最近三篇摘要和账号定位。
1. 先运行事实风险和原创增量评审。
2. 事实评审输出 `veto` 时，跳过吸引力和增长优化，只汇总 P0 事实修改并交回写作流程完整重写。
3. 原创不足时先补素材、利益关系、规则拆解或原创框架，不能只增强情绪。
4. 第一阶段通过后，运行用户吸引力、平台增长评审，并调用根级 `toutiao-article-auditor`。审核输入必须包含用户原始观点、事实边界、目标账号、文章规格、5个标题、摘要、正文、最近三篇文章的开头/小标题/结尾和当前重写轮次。
5. 合并全部修改并按 `P0 → P1 → P2 → P3` 排序。
6. `toutiao-article-auditor` 返回 `rewrite` 时，把它的 `rewrite_brief`、`preserve`、`discard` 和 `next_round_focus` 纳入唯一修改单，交给主写作流程从空白稿完整重写，不使用局部同义词补丁；旧标题、小标题、章节顺序和结尾默认作废。
7. 每轮重写后重新运行全部评审，最多 3 轮。

## 优先级

- `P0`：事实、来源、因果、名誉、法律和群体攻击。
- `P1`：选题角度、标题、首屏、封面和正文承诺。
- `P2`：原创增量、信息递进、利益关系和评论设计。
- `P3`：句式节奏、模板重复和 AI 痕迹。

## 通过规则

- 用户吸引力不低于 80。
- 平台增长不低于 75。
- 原创增量不低于 75 且至少两项真实增量。
- `toutiao-article-auditor` 不低于 85、风险为低、`hard_failures` 为空且 `verdict=pass`。
- 事实质量不低于 90 且无 `veto`。
- 加权总分不低于 80。

权重：用户吸引力 30%，平台增长 25%，原创增量 20%，AI 痕迹 15%，事实质量 10%。事实 `veto` 时不计算总分。

## 冲突处理

- 流量建议与事实边界冲突时事实优先。
- 吸引力与原创建议冲突时先保留原创问题，再重做标题和首屏。
- 去 AI 修改不得删除关键证据或改变事实含义。
- `toutiao-article-auditor` 发现标题组、开头、任一章节或结尾存在硬性失败或中高风险时，即使其他评分过线也必须完整重写，直到 `verdict=pass` 或达到重写上限。
- 同一原句被多个评审指出时合并为一条，标明受影响维度。

## 统一协议

每个评审输出内部 JSON：

```json
{
  "reviewer": "reviewer-id",
  "score": 0,
  "decision": "pass | revise | veto",
  "risk": "low | medium | high",
  "evidence": [
    {"quote": "文章原句", "issue": "具体问题", "impact": "对点击、留存、事实或推荐的影响"}
  ],
  "revisions": [
    {"priority": "P0 | P1 | P2 | P3", "location": "标题 | 首屏 | 正文段落 | 结尾 | 配图", "instruction": "可直接执行的修改动作", "expected_effect": "预期改善维度"}
  ]
}
```

修改意见必须引用具体原句、位置或缺失信息，不使用“更有吸引力、减少AI感、加强冲突、提高原创度”等空泛指令。

## 重写上限

- 初稿不计入重写轮数，最多执行 3 次完整重写。
- 任一轮全部过线立即停止。
- 第 3 轮后仍有任一单项不过线、总分低于 80，或 `toutiao-article-auditor` 未返回 `pass`，停止重写并标记 `备选草稿｜需人工复核`。
- 不开始第 4 轮，不降低评分门槛。

## 简版评分卡

```markdown
**发布评审**

- 用户吸引力：[分数]/100
- 平台增长：[分数]/100
- 原创增量：[分数]/100
- 人工感与AI痕迹：[分数]/100｜低/中/高风险
- 事实与名誉风险：[分数]/100
- 综合评分：[分数]/100
- 自动重写：[0-3]轮
- 发布结论：可直接发布/备选草稿｜需人工复核
- 主要优化：[已经完成的关键修改或剩余阻塞项]
```

用户明确要求“只给正文”时内部仍执行全部评审，但隐藏评分卡。
