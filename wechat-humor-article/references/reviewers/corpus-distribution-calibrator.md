# 语料分布校准器

检测器抓的不是"你用了什么手法"，而是"你的语料分布像不像人类"。本文件定义6项底层分布指标，在写作前提取范文基准、在写作后逐项检测。只检查分布指标，不重复模板词和结构检查，不声称能证明作者身份。

## 为什么需要这一层

现有 ai-trace.md 和 toutiao-article-auditor 聚焦表层模式（禁用模板词、检查段落对称、检查章节结构）。但 AI 检测器认的是底层语料分布指纹——句长方差、反问密度、段落密度、情绪曲线、口语标记词频率、信息密度。这些指标现有规则完全未覆盖或只有定性描述（"长短句自然"），没有量化标准。

## 6项分布指标

### 1. 句长方差

**问题**：AI 输出的句子长度过度均匀，80%集中在同一区间。人类写作的句长方差远大于模型默认分布。

**量化标准**：
- 正文句长标准差须 ≥ 12字
- 最长句须 ≥ 45字（一个完整意思一口气说完的长句）
- 10字以内短句须 ≥ 3句（不是碎片化换行，而是语气断句）
- 禁止80%以上句子集中在同一长度区间（以10字为一段划分）

**检查方法**：按句号、问号、感叹号切分正文，计算每句字数，画分布直方图。如果分布呈现正态钟形曲线，判为不达标。

### 2. 反问句限额

**问题**：AI 喜欢每段用一个反问句做情绪收束，形成"反问公式"。人工范文的反问句少且为结构性问句（承上启下），不是情绪性煽动。

**量化标准**：
- 正文每800字反问句不超过2个（约1200字文章不超过3个）
- 反问句必须出现在结构性转折处（段落首句或小标题后首句），用于引出新问题
- 禁止反问句出现在段尾做收束——这是 AI 最典型的反问公式
- 连续两个段落不得都以反问句结尾

**检查方法**：统计全文问号数量和位置，标记每个问号是结构性问句还是情绪性问句。情绪性问句 = 答案显而易见、目的是煽动而非引出信息。

### 3. 段落密度

**问题**：AI 把"段落短适合手机阅读"理解成"每句话都换行"，导致全文像列表而非文章。人工范文也分段，但段内有2-4句话形成完整论证。

**量化标准**：
- 正文须有至少3个段落包含3句以上（≥60字）——这些是"信息密度段落"
- 单句段落（一句话成段）不超过总段落的40%
- 禁止连续3个以上单句段落
- 多句段落不是密密麻麻的大段：3-4句话完成一个论证单元即换行，仍保持手机阅读友好

**检查方法**：统计每个自然段的句数和字数，计算单句段落占比。如果超过40%，判为过度碎片化。

### 4. 情绪曲线

**问题**：AI 文章从头到尾保持同一情绪强度——持续亢奋或持续冷静。人工范文有明显的起伏：叙述→分析→判断→展望，情绪在不同段落有高低变化。

**量化标准**：
- 正文须包含至少1段"冷静分析段"——不带情绪词、不做判断、只陈述事实和因果推导
- 正文不得连续4段以上保持同一情绪强度（全亢奋或全冷静都算）
- 情绪曲线应有至少1次明显升降：可以是"亢奋开头→冷静分析→判断升温→克制收尾"

**检查方法**：逐段标注情绪强度（高/中/低），画情绪曲线。如果全程高位或全程低位，判为不达标。冷静分析段 ≠ 自我降温段（后者是批评后机械补"对方也有难处"）。

### 5. 口语标记词黑名单

**问题**：AI 假装口语时会使用"说白了""翻译成人话就是""换个说法""一句话总结""换句话说"等元评论标记词。这些词本身是 AI 的口语化模板。人工范文的口语化通过具体动词和场景实现，不通过自我标注。

**量化标准**：
- 禁用以下元评论标记词：
  - "说白了""翻译成人话就是""换个说法""一句话总结""换句话说"
  - "简单来说""直白点说""通俗讲""讲白了"
  - "这什么意思呢""怎么理解呢""这意味着什么"
- 口语化必须通过具体动词（"点名""吃了闭门羹""一巴掌"）和场景（"站在你门口说要进来看看"）实现
- 1-2处自然的口语表达可以保留，但不能依赖标记词批量制造口语感

**检查方法**：全文搜索上述标记词，命中即判为不达标。

### 6. 信息密度

**问题**：AI 倾向于"一句一信息"——每句话只做一件事（介绍身份/说事实/给判断）。人工范文经常把多层信息编进一句话，信息密度更高但更"乱"——这种"乱"恰恰是人味。

**量化标准**：
- 正文须有至少4句"复合信息句"——一句话包含2个以上独立事实、因果关系或对比关系
- 复合信息句示例：人工范文"USCC是美国国会授权的正式评估机构，薛瑞福7月下旬才刚刚率团访问大陆，因试图打探科技企业底牌遭拒，而气急败坏抱怨自己'被冷落'，随后就针对台海局势说了这番话" → 身份+事件+情绪+后续动作，四层叠在一句
- 禁止全文都是"一句一信息"的平铺句——每句话只做一件事，像百科卡片

**检查方法**：逐句标注信息层数（1层=单一信息，2+层=复合信息），统计复合信息句数量。如果全文不足4句复合信息句，判为不达标。

## 写作前校准协议

在读取范文形成借鉴卡后（见 local-reference-library-and-archive.md 第3.5步），执行以下校准：

1. 统计选中范文的6项分布指标实际值
2. 记录为本次写作的 `distribution_targets`
3. 写作时以范文分布值为目标基准，不是以 AI 默认分布为准

内部借鉴卡新增字段：

```json
{
  "distribution_targets": {
    "sentence_length_std": 15,
    "max_sentence_length": 65,
    "short_sentence_count": 5,
    "rhetorical_question_limit": 3,
    "single_sentence_paragraph_ratio": 0.25,
    "multi_sentence_paragraph_count": 4,
    "calm_analysis_paragraphs": 1,
    "info_density_sentence_count": 6,
    "oral_marker_blacklist": ["说白了", "翻译成人话就是", "换个说法", "一句话总结", "换句话说"]
  }
}
```

## 写作后检测协议

在 AI 痕迹审核完成后（ai-trace.md 或 toutiao-article-auditor），执行以下检测：

1. 逐项检查6项分布指标
2. 输出内部 JSON，包含分项判定和具体不达标位置
3. 任一指标不达标时，标记为 `distribution_fail`，需要修改后重新检测

输出格式：

```json
{
  "reviewer": "corpus-distribution-calibrator",
  "decision": "pass | fail",
  "metrics": {
    "sentence_length_variance": {"status": "pass | fail", "detail": "标准差X字，最长句X字，短句X句", "fix_location": "不达标的具体位置"},
    "rhetorical_question_density": {"status": "pass | fail", "detail": "全文X个反问句，其中情绪性X个", "fix_location": ""},
    "paragraph_density": {"status": "pass | fail", "detail": "单句段落占比X%，多句段落X个", "fix_location": ""},
    "emotion_curve": {"status": "pass | fail", "detail": "冷静分析段X个，连续同强度段落X段", "fix_location": ""},
    "oral_marker_words": {"status": "pass | fail", "detail": "命中标记词：XX、XX", "fix_location": ""},
    "information_density": {"status": "pass | fail", "detail": "复合信息句X句", "fix_location": ""}
  },
  "revisions": [
    {"priority": "P2", "location": "具体段落", "instruction": "可直接执行的修改动作", "expected_effect": "预期改善指标"}
  ]
}
```

## 与现有评审的关系

- 本文件只检查6项分布指标，不重复模板词检查（ai-trace.md 负责）、不重复章节结构检查（toutiao-article-auditor 负责）、不重复事实核验（fact-risk.md 负责）
- 本文件检测结果作为 ai-trace.md 和 toutiao-article-auditor 的输入之一，不独立决定发布结论
- 本文件不声称能证明作者身份，不输出"人工特征百分比"，只报告6项指标是否达标
- 用户提供第三方检测结果时，将其作为回归样本分析，对照6项指标找出不达标项

## 修改优先级

分布不达标时的修改优先级：

1. **P1**：口语标记词黑名单命中 → 直接删除或替换为具体动词
2. **P2**：反问句超限 → 删除情绪性反问，保留结构性问句
3. **P2**：句长方差不足 → 合并相邻短句为长句，或在均匀段落中插入短句断奏
4. **P2**：段落过度碎片化 → 合并相邻单句段落为多句论证段
5. **P3**：情绪曲线单调 → 在亢奋段中插入冷静分析段
6. **P3**：信息密度过低 → 把相邻的平铺句合并为复合信息句
