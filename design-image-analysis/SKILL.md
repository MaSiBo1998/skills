# 设计图图片解析

本 skill 只负责把 `design/` 文件夹里的设计图图片解析成可执行的 UI 规格清单。不要直接改业务代码；页面实现交给 `design-image-restore`。

## 基准规则

- 所有设计图默认以 `375px` 宽作为移动端设计基准。
- 若原图宽度不是 375，按 `scale = 375 / 原图宽度` 换算所有横向、纵向尺寸和坐标。
- 输出尺寸统一使用换算后的 375 基准数值。
- 需要落地 CSS 时，优先给出 `px` 基准值；项目已有 `rem`、`vw`、`rpx` 或 postcss 转换规则时，再说明对应换算关系。
- 不把截图中的系统状态栏、浏览器栏、调试浮层计入页面内容；无法确定时标记为“需确认区域”。

## 读取流程

1. 确认项目根目录。
2. 读取项目根目录 `design/` 文件夹。
3. 收集 `.png`、`.jpg`、`.jpeg`、`.webp`、`.gif` 图片。
4. 按文件名、尺寸、页面内容归类页面、弹窗、空状态、错误态、局部组件和流程状态。
5. 若 `design/` 不存在或没有图片，阻断并提示补充设计图。
6. 若多张图片无法判断顺序，列出候选关系并询问用户。
7. 输出页面映射时说明排序依据：文件名、画面内容、流程语义、尺寸或用户提供顺序。

## 解析内容

对每张设计图输出以下内容：

- 图片信息：文件名、原始宽高、换算比例、375 基准高度。
- 页面结构：顶部区域、主体区域、底部操作区、弹窗、列表、卡片、表单、导航等。
- 布局尺寸：关键容器的 x/y/width/height、padding、margin、gap、圆角、边框。
- 文本规格：文案、字号、行高、字重、颜色、对齐、最大行数。
- 色彩规格：背景色、主色、辅助色、边框色、阴影色，尽量给出 hex。
- 图片与切图需求：logo、icon、插画、背景、装饰图，标注位置、尺寸、建议名称。
- 交互状态：按钮禁用/可用、选中态、输入态、错误态、加载态。
- 响应式注意点：窄屏溢出风险、长文案风险、安全区或底部固定按钮风险。

## 切图匹配建议

解析阶段只提出切图需求和候选，不直接重命名资源：

1. 优先扫描 `src/assets`，并按项目实际结构补充扫描 `src/assets/images`、`src/assets/img`、`assets`、`public` 中与设计元素相似的文件名和图片类型。
2. 对每个设计元素给出候选资源路径。
3. 候选不足时标记“缺失切图”，并建议规范名称。
4. 建议命名遵循：
   - `icon-场景-含义.ext`
   - `bg-场景-含义.ext`
   - `illus-场景-含义.ext`
   - `logo-品牌-变体.ext`

## 输出格式

交付给 `design-image-restore` 的分析清单必须包含：

```markdown
## 设计图解析清单

### 基准
- 设计基准宽度：375px
- 换算规则：scale = 375 / 原图宽度

### 页面映射
| 设计图 | 页面/状态 | 说明 |
| --- | --- | --- |

### 页面规格
#### <设计图文件名>
- 原始尺寸：
- 375 基准尺寸：
- 页面结构：
- 关键布局：
- 文本规格：
- 色彩规格：
- 切图需求：
- 资源候选：
- 页面顺序依据：
- 需确认项：

### 复原优先级
1. 首屏结构和固定底部操作区
2. 关键切图和主按钮
3. 列表、表单、弹窗状态
4. 细节间距和长文案适配
```

## 约束

- 不凭空补设计图中不存在的业务模块。
- 不把不确定尺寸说成确定值；用“约”或“需确认”标注。
- 不直接修改资源目录；资源复用、重命名和引用更新交给 `design-image-restore`。
- 不跳过 375 宽基准换算。
