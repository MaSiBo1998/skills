# 分步创作流程

## 阶段顺序

| 当前阶段 | 必须完成 | 下一阶段 |
| --- | --- | --- |
| `direction_selection` | 用户明确小说方向 | `route_selection` |
| `route_selection` | 生成三套路线，用户选择一套 | `outline_design` |
| `outline_design` | 确认整书大纲与动态分卷 | `protagonist_design` |
| `protagonist_design` | 确认主角完整行为依据 | `family_design` |
| `family_design` | 确认家庭背景与内部关系 | `key_characters_design` |
| `key_characters_design` | 确认第一卷核心角色 | `relationships_design` |
| `relationships_design` | 确认双向关系与变化节点 | `world_design` |
| `world_design` | 确认时代、地点和事实边界 | `outline_review` |
| `outline_review` | 人物与大纲双向校准并重新确认 | `packaging` |
| `packaging` | 确认书名与简介 | `opening_design` |
| `opening_design` | 确认前三章卡、标题和钩子 | `ready_to_write` |
| `ready_to_write` | 用户明确说开始正文 | `writing` |

## 每轮交互格式

每轮只处理当前阶段：

1. 用不超过 5 条列出已确认事实。
2. 标出当前草案；不要把草案称为设定。
3. 只问 2—3 个会改变结果的问题。
4. 用户回答后总结本阶段结果并请求确认；未确认不推进。

用户没有想法时，给 2—3 个真正不同的候选并说明影响。用户说“你决定”时只代选当前阶段，记录 `user_delegated`；除非用户明确说“后续全部由你决定”，不得扩大授权。

## 三套路线合同

三套路线必须在长期发动机上不同，不能只是换名字：

- `id`、路线名、核心看点
- 主角基本定位
- 长期主线
- 主要升级方式
- 预计字数区间
- 预计卷数
- 结局方向
- 最大风险或写作难点

选定路线前不生成分卷剧情。被放弃路线保留为未选草案，不合并进事实源。

## 动态分卷合同

每卷必须包含：

- `number`、暂定卷名
- `stage_goal`：本卷结束时局面发生什么变化
- `main_conflict`：持续阻力
- `key_events`：3—5 个关键事件
- `stage_payoff`：本卷兑现的主要爽点或情绪回报
- `character_change`：人物关系或人格变化
- `climax`：卷末高潮
- `next_hook`：下一卷具体承诺
- `status`：`draft`、`needs_revision` 或 `confirmed`

卷数由故事规模、升级层级和预计字数决定。不得先定十卷再填内容。

## 爽文胜负校准

- 先区分“阻力存在”“失败可能发生”和“主角实际失败”，三者不能混写。
- 爽文卷纲可以每卷都有阻力，但不应机械地每卷都有败局；阶段爽点和卷末高潮必须体现主角赢得了什么新优势。
- 用户要求少失败时，优先采用：提前发现风险、付出可控机会成本、被围堵后反包围、短期少赚换长期控制、对手判断失误后主角扩大优势。
- 不得为了补人物成长而擅自加入连续亏损、召回、平台崩盘、退出市场、公开重大事故或长期压抑段落。
- 真正大败必须回答三个问题：它是否符合用户要求的爽感、是否产生更大的后续兑现、是否得到当前大纲阶段的明确确认。任一不成立就改为阻力或险情，不让它实际落地。

## 人物设计门禁

主角必须能回答：想要什么、为什么现在行动、擅长什么、会因什么犯错、最怕失去什么、什么事绝不做、压力下怎么说话和行动。

家庭必须能回答：谁和主角共同生活、收入与债务从哪里来、家庭内部谁欠谁、谁支持或阻碍主角、哪段经历塑造了主角的金钱观与关系观。

核心配角只按第一卷功能创建。每段关系必须记录双方不同视角，不能只写“朋友”“敌人”。

## 大纲回看

逐卷检查关键事件：

- 人物是否有足够动机做这件事。
- 人物是否拥有当时可得的信息和资源。
- 家庭、关系和现实边界是否允许事件发生。
- 潜在失败代价是否真实；若是爽文，风险是否被合理转化为反杀或可控代价，而不是机械落成实际败局。

任一不成立，将对应卷标记 `needs_revision`。修改后的卷必须再次得到用户确认，才可恢复 `confirmed`。
