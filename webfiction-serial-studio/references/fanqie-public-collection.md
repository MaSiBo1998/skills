# 番茄公开热点采集合同

## 允许的数据源

只允许匿名访问 `https://fanqienovel.com/` 下的公开页面：

- `rank` 与 `rank/*`：男女频阅读榜、新书榜、分类榜。
- `page/*`：作品公开详情页，且只读取标题、作者、标签、分类、更新状态和公开短字段。
- `reader/*`：只跟随详情页公开目录提供、无需登录即可正常阅读的章节，用于真实内容抽样和结构拆书，具体流程见 [公开章节实读拆书](public-chapter-analysis.md)。

公开网页不需要用户额外声明用途或授权。禁止的是批量镜像整站/整本正文、访问隐藏接口、绕过登录或验证码、读取付费/受限内容，而不是正常打开公开章节。

## 真实榜单口径

当前公开 `rank` 页面只提供四种主榜口径：男频阅读榜、男频新书榜、女频阅读榜、女频新书榜。页面没有独立“完结榜”入口。所谓“完结作品观察集”必须由阅读榜卡片中的 `已完结`、`最近更新：...（完结）`、`大结局`、`终章` 或作品公开状态识别，并始终注明它不是独立完结榜。

不能把新书榜的近期点击入口直接当成 200 万字可持续性证据。市场报告必须分别回答：

- 新书榜当前用什么书名、身份、危机和关系承诺吸引点击；
- 阅读榜中的完结样本公开展示了哪些能撑到阶段结局的发展方向；
- 两者有哪些重合信号，哪些只是一时包装。

## 快照字段

每次成功采集生成 JSON，至少包含：

```json
{
  "schema_version": 2,
  "captured_at": "2026-07-13T08:00:00Z",
  "source": "https://fanqienovel.com/rank",
  "status": "fresh",
  "boards": [
    {
      "name": "女频阅读榜",
      "genre": "古风世情",
      "source_url": "https://fanqienovel.com/rank/0_2_1139",
      "entries": [
        {
          "rank": 1,
          "title": "示例",
          "author": "示例",
          "url": "https://fanqienovel.com/page/...",
          "public_tags": ["重生", "创业"],
          "public_blurb": "公开简介的有限长度采集值",
          "latest_update": "第500章 大结局（完结）",
          "updated_at": "2026-07-12 20:00",
          "reading_count": "20万",
          "completion_status": "completed",
          "evidence_method": "public_rank_card",
          "text_quality": {"private_use_ratio": 0, "needs_visual_review": false}
        }
      ]

  ],

}
```

`public_blurb` 最多保存榜单卡片公开简介前 800 个字符。榜单采集器本身不抓章节正文；需要判断真实内容时，转入独立的公开章节实读流程，保存章节覆盖范围和抽象结构结论，而不是把正文复制进快照。

## 自定义字体与视觉复核

番茄网页可能用自定义字体把 DOM 字符映射到私用区。采集器必须计算 `private_use_ratio`；达到阈值时：

1. 把该条标为 `needs_visual_review: true`，不得拿乱码做高置信关键词统计；
2. 只截取榜单卡片所在公开页面，保存到 `review-screenshots/`，不进入正文页；
3. 由当前模型视觉读取或人工复核前 10–20 条，把校正值写入独立 `visual-review.json`，不可覆盖原始快照；
4. 分析器通过 `--visual-review` 合并校正值，并把 `evidence_method` 标为 `public_rank_card_visual_review`；
5. 无法视觉复核时明确报告数据质量不足，不猜测书名或内容。

视觉复核文件最小结构：

```json
{
  "reviewed_at": "2026-07-13T09:00:00Z",
  "entries": [
    {
      "url": "https://fanqienovel.com/page/...",
      "title": "视觉核对后的公开书名",
      "author": "公开作者名",
      "public_tags": ["公开标签"],
      "public_blurb": "只记录用于方向判断的有限公开简介",
      "completion_status": "serializing"
    }
  ]
}
```

## 缓存与降级

- 默认缓存 24 小时。有效缓存存在时返回 `status: cached`，不再次访问页面。
- 单轮最多访问 30 个页面，串行执行；默认采样男频都市日常/都市脑洞/都市种田与女频现言脑洞/年代/古风世情的新书榜和阅读榜，每榜前 20 条。用户可用 `-Genres` 改成目标赛道；每次浏览器动作默认 5 秒硬超时，整轮扫描默认 35 秒。
- 发生登录、验证码、限流、访问失败、robots/站点规则限制或 DOM 结构不匹配时，立即停止采集。
- 若存在历史有效快照，标注 `status: stale` 并保留失败原因；若没有快照，输出空结果与人工补充提示，不编造热门结论。

## 趋势解释

报告不能停在赛道排名分。至少要给出书名公式、主角身份、核心优势、开局危机、关系承诺、公开简介展示的发展路径、新书信号与完结观察信号。所有内容方向都要能回指标题、标签或公开简介；没有多日快照时，必须说明没有增长趋势证据，榜单高位也不等于商业成功保证。
