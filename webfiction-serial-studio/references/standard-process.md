# 标准网文生产流程

## 十二阶段状态机

| 阶段 | 核心产物 | 关键确认 |
| --- | --- | --- |
| `idea_intake` | 原始创意、题材定位、核心幻想、目标读者、预计篇幅 | 小说方向 |
| `story_positioning` | 三套路线、读者承诺、基调、爽感、感情比例、失败容忍、雷点 | 最终路线 |
| `global_outline` | 开局危机、长期主线、升级路线、中期转折、终局与结局 | 整书主线 |
| `volume_design` | 全部分卷简纲与逐卷深化 | 整体分卷 |
| `world_research` | 时代、地点、行业、经济、技术、医疗、教育与来源 | 改变主线的世界规则 |
| `character_system` | 主角、家庭、对手、伙伴、感情角色和双向关系 | 核心人物 |
| `outline_calibration` | 人物动机、信息、资源与分卷事件反查 | 实质变化部分 |
| `timeline_foreshadow` | 时间线、关键节点、伏笔与回收窗口 | 主线级节点 |
| `packaging_opening` | 书名、简介、标签、前三章卡与三章大钩子 | 包装与前三章 |
| `serialization` | 章节卡、事实卡、正文、审稿报告、状态更新 | 不逐章强制确认 |
| `volume_review` | 卷级兑现、人物变化、伏笔清理、下一卷启动 | 长期主线变化 |
| `completion` | 结局、全书时间线、人物结局和伏笔回收 | 完结版本 |

## 每轮固定动作

1. 读取当前目录的 `series-state.json`。
2. 读取 `workflow_progress`，先说明项目、阶段、上次完成内容和下一步。
3. 只执行 `next_action`；用户说“继续”不等于确认。
4. 需要用户决定时，只展示当前阶段的 2—3 个高价值选择。
5. 普通资料、次要角色和局部节奏由 skill 补齐，不反复打断。
6. 每次生成、确认或修订后立即更新状态并刷新 `00-skill读取入口.md`。

## 回退与影响

- 用户修改整书大纲、分卷、世界规则、核心人物或核心关系时，先运行影响分析。
- 受影响的阶段标记为 `needs_revision`；只重新确认发生实质变化的内容。
- 普通配角、措辞和不改变长期主线的细节不触发全链回退。
- 正文修订使用 `project_status=revising`，完成后恢复 `writing` 和原续写章节。
