# 创意生成 V2

本流程用于前三章、重点章、整组重写，以及用户明确指出“逻辑没错但不好看”的正文。目标是先扩大有效创意差异，再做选择和约束，不让同一模型一次写完并自行宣布通过。

## 最小场景简报

正文生成阶段只读取当前章节必需信息，固定记录：人物当下欲望、直接阻力、失败代价、关系温度、权力位置、已知/误解/隐瞒、情绪转折、感官锚点、当章兑现、章末承诺、不可违反的硬门禁，以及已确认但本章不应主动展示的背景。

不得把完整人物卡、整书大纲、远期产业规划和审稿报告直接交给正文生成阶段。人物不能替作者复述需求、规则或商业结论。

## 三套差异化候选

每章先写三套场景路线，再分别写候选正文。三套候选至少在开场动作、主要冲突、关系转折、章末钩子四项中的三项不同。

- 一套优先放大社会性难堪、身份差或地位冲突。
- 一套优先放大关系误读、隐瞒和潜台词。
- 一套优先放大交易失败、时间压力或对手反制。

三套候选不是固定文风模板。具体章节不适合某种发动机时，换成同等差异度的冲突来源。禁止只改措辞、语序、标题或段落顺序。

## 匿名两两比较

候选匿名为 X、Y、Z。评审只读取候选正文和必要的上一章结尾，不读取设计意图、大纲、作者说明或既有审稿结论。

- 继续阅读欲望：30%。
- 人物辨识度：20%。
- 冲突与转折：20%。
- 对白与潜台词：15%。
- 兑现与章末钩子：15%。

执行 X 对 Y、X 对 Z、Y 对 Z 三轮比较。胜出稿必须至少赢两轮；没有明显胜者时重新生成，不用平均分强行选稿。

## 独立重写

从胜出候选提取有效场面、人物动作、情绪转折和关系变化，随后关闭候选正文，重新写一份完整终稿。不得复制粘贴不同候选的优点段落。

改写时把解释性对白变成动作、拒绝、误读和后果；删除总结式心理活动、整齐排比和过度正确的因果说明；允许人物判断不完整、反应不体面、临时改口或做出带代价的选择；商业信息只保留完成当前交易所需的部分。

## 后置硬校验

创意版本确定后，再检查人物、情节、逻辑、时间、空间、职业流程、时代工具和商业可行性。校验只修真实错误，并尽量保持原有戏剧功能，不借机加入设定说明。

## 新鲜读者测试

测试者不读取大纲、人物卡、创作简报和评审报告，只阅读正文并回答：

1. 是否愿意继续读，理由是什么？
2. 第一次想跳读的位置在哪里？
3. 最像模型生成的三处是什么？
4. 能记住哪些人物，各自凭什么被记住？

自动测试只用于筛选，不得替代用户最终判断。报告必须把“事实是否合格”和“是否产生阅读欲望”分开。

## 保存约定

每轮生成保存到 `创作实验/<轮次>/`：

- `00-最小场景简报.md`
- `候选/第XXX章-X.md`、`Y.md`、`Z.md`
- `01-匿名两两评审.md`
- `02-新鲜读者测试.md`
- `03-事实与连续性校验.md`
- `04-新旧版本盲测.md`

候选文件开头必须写明 `开场动作`、`主要冲突`、`关系转折`、`章末钩子` 四项元数据，供流程校验器检查差异。只有终稿发生的事实进入 `series-state.json`。
