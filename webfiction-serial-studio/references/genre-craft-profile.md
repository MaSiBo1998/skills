# 赛道级可读性档案

## 输入和边界

赛道档案来自公开榜单信号、公开读者反馈和用户有权提供的材料。它只保留跨作者、可解释、可迁移的创作技法，不保存原文，不用任何作者姓名作为写作指令。

## 输出模板

```markdown
# <赛道>可读性档案

## 读者承诺
- 主角在什么压力下解决什么问题，读者为何愿意继续看。

## 开局与信息揭示
- 前 3 章应建立的危机、欲望、反差和未解问题。
- 哪类信息应通过行动/对话揭示，哪些可暂缓。

## 章节节奏
- 目标 -> 阻力 -> 选择 -> 代价/反转 -> 下一章钩子。
- 场景、行动、对话、内心和说明之间的推荐取舍。

## 人物互动
- 主角与关键角色的利益冲突、情绪张力与关系变化节奏。

## 容易失速的风险
- 重复打脸、连续旁白解释、无代价升级、角色失忆式和解、支线长期不回收。
```

## 自然文风检查

- 每个场景至少推动一个人物关系、信息状态或事件局面；不要用无变化的对话填充篇幅。
- 让人物以各自的目标、知识边界和关系位置说话，避免所有人使用同一语气。
- 用具体行动、环境反应和选择后果承载情绪；减少直接给情绪和主题贴标签。
- 保留句式、段落和场景切换的自然变化，但不为了迎合检测工具机械替换词语。
