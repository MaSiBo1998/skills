# 01 Positioning

## 定位

`frontend-dev-workflow` 是一个 Claude Code Skill，用于在已有前端项目中自动推进一轮开发工作。

它解决的问题不是“如何创建前端项目”，而是“当项目已经存在时，如何让 Claude Code 更稳定地完成需求开发”。

## 核心价值

- 降低前端需求执行时的上下文切换成本
- 提高 Claude Code 对现有项目规范的适配能力
- 减少无关重构和误改
- 让需求开发、自检和交付说明形成统一流程

## 目标用户

- 在已有 React / Vue 项目里让 Claude Code 自动开发的人
- 希望 Claude Code 优先复用现有代码体系的人
- 希望前端改动更可控、更工程化的人
