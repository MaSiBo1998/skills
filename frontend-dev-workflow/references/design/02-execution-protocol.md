# 02 Execution Protocol

## 标准执行链路

1. 需求理解
2. 技术栈嗅探
3. 精准定位
4. 最小实现方案
5. 自动开发
6. 自检
7. 交付说明

## 关键策略

### 先嗅探
在修改前先识别：
- 包管理器与脚本命令
- 页面与组件组织方式
- 样式体系
- UI 库
- 状态管理与请求封装

### 最小修改
任何实现都优先满足：
- 范围小
- 易复用
- 易回归验证
- 不改无关代码

### 默认自动推进
只要没有关键歧义，就应自主推进开发，而不是频繁打断用户。

### 自检闭环
尽量执行类型检查、Lint、构建或局部验证，并在交付时说明执行结果。
