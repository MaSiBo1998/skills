# App 内嵌协议/隐私开发问答

适用于协议/隐私相关的 App 内嵌开发问题，例如 App WebView 加载哪类协议链接、H5 如何承接原生入口、官网隐私入口与 App 内链接如何对齐、协议展示验收口径如何判断。

该 reference 当前只作为场景入口和处理边界，固定实现规则待后续需求确认后再沉淀。

## 处理边界

- 可以回答：当前项目协议链接来源、App WebView 可加载路径、官网入口与 App 内链接是否一致、H5 路由/iframe/静态 HTML 的适用差异、验收需要看哪些页面和链接。
- 暂不固定：具体 App 原生方法名、国家差异、链接配置后台、埋点/上报规则、灰度策略，除非用户后续明确要求沉淀。
- 必须基于项目实际代码、已有协议链接或用户提供资料作答；无法确认时列出待确认项。
