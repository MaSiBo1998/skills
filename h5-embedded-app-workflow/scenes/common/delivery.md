# 交付（通用模块）

所有场景共用的交付步骤模板。

## 输出内容

1. **修改说明**：本场景修改了哪些文件/模块/页面
2. **设计还原汇总**（如有 Figma 或本地设计图分析）：组件复用情况、样式还原覆盖率
3. **接口映射汇总**（如有接口解析）：映射完成数 / 需人工确认数
4. **测试结果**：CHECKLIST.md 检查项通过率及失败项说明
5. **待用户验收项**：需要用户在真实设备/浏览器上手动验证的功能点

## Skill 改进建议

验收时列出本次执行中发现的 SKILL.md 未覆盖问题、用户提出的优化建议。

**列出后必须询问用户**：发现的问题是否要更新到技能文件中？用户确认后立即修改对应的 Skill 文件。

**用户拒绝**则仅在本轮交付中记录，不写入技能文件。

## Checkpoint 清理

交付完成后删除 `.workflow-checkpoint.json`，工作流结束。
