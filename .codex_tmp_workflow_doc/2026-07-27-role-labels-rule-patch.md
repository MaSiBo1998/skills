# 角色称谓规则补丁

- `objective`：原创生活故事、假设家庭案例和家常劝导不再自行虚构人名；角色称谓按场景稳定切换；家庭共同承担必须由每个成员的表达与行动兑现；温情句必须由具体情节托住。
- `scope`：二次优化“人到中场”首篇成稿和本地写作检查表；更新 `wechat-humor-article` 的执行规则、发布检查和定向回归样例。
- `success_criteria`：内容项目中已知虚构姓名搜索为零；场景内不机械交替角色称谓与代词；女儿拥有符合高中生身份的表达和行动；skill 新增称谓一致性、共同承担和温情落地规则；两个定向回归样例可拦截对应问题。
- `boundaries`：不替换公开新闻中已经核实的人名；不替换用户明确提供并要求保留的真实姓名；不让未成年子女承担不合年龄的经济压力；不修改与本规则无关的账号定位和热点流程。
- `blocking_questions`：无，用户已明确确认修改并写入 skill。
- `optimization_level`：规则补丁。
