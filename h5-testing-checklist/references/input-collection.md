# 输入收集（通用模块）

所有 H5 工作流场景共用的输入收集步骤。按场景收集必填项，可选项缺失不得阻断流程。

## 输入矩阵

| 场景 | 必填输入 | 可选输入 |
| --- | --- | --- |
| A 架构改造 | 项目根目录、是否 Vite/npm、是否已有 vendor 架构 | 目标构建命令 |
| B 功能/API 开发 | 项目根目录、本次需求类型 | 产品名、业务国家；接口文档仅字段替换或接口适配时必填 |
| C 首复贷开发 | 项目根目录、产品名、业务国家、本次需求类型 | 接口文档仅新文档/字段替换时必填 |
| D 进件开发 | 项目根目录、产品名、业务国家、本次需求类型 | 接口文档仅新文档/字段替换时必填 |
| E 协议 HTML | 4 份协议文档、目标 `public` 目录 | 协议链接 |
| F 设计图复原 | 项目根目录、`design/` 文件夹、目标页面或路由 | 产品名、业务国家 |
| G 国家发布 | 项目根目录、`release-env` | 手动指定国家 |
| H 工作流自我更新 | 要沉淀的问题 | 目标 skill；未指定时由工作流判断 |

## 执行规则

- 列出已拿到和缺失的输入
- 缺失当前场景必填输入时明确列出并要求补充
- 将收集到的输入路径写入 checkpoint context（如 `product_name`、`country`、`api_doc_path`、`project_config`、`target_route`、`release_env_path`）
- 场景 B 普通功能/API 开发未确认产品名或国家时可以继续；若用户提供则写入 checkpoint
- 场景 F 设计图复原未确认产品名或国家时可以继续；目标页面或路由无法判断时必须询问
- 若场景 D 的国家为 `Guatemala` / `GT` / `危地马拉`，在后续步骤加载 `h5-apply-flow/references/country-guatemala.md`
- 若场景 D 的国家为墨西哥、哥伦比亚或其他国家，不能套用危地马拉规范；要求用户提供该国家差异或按通用 Apply 流程执行

## 可选：项目配置信息

完成当前场景必填项收集后，若涉及接口/字段替换或新项目迁移，询问用户"是否需要提供项目配置信息（如 app 名称、业务线、域名、加密规则、响应码等）？"

- **用户选择"是"**→ 收集用户提供的配置项（参考 `h5-api-mapping/references/project-config.md` 中的配置项清单），写入 checkpoint context 的 `project_config` 字段
- **用户选择"否"**→ 跳过，使用代码中现有配置
