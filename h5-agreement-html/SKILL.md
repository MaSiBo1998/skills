# H5 协议 HTML

本 skill 负责两类协议任务：协议文档转静态 HTML，以及官网协议入口/Tab/iframe 展示。不得擅自改写法律正文。

## 执行方式

1. 判断任务类型：
   - 协议文档转 HTML：收集 4 份本地协议文档、可选协议链接、目标 `public` 目录。
   - 协议展示入口：收集目标路由、默认选中协议、Tab 协议列表、线上协议链接、旧入口兼容要求。
2. 加载 `references/agreement-html.md`，按其中原流程执行。
3. `.docx` 只允许使用已安装的 `docx` skill 解析。
4. 文档转 HTML 时，链接只用于文件命名，不作为正文来源。
5. 协议展示入口时，优先参考同类项目既有实现，使用 Tab 切换 iframe 展示线上协议链接。

## 约束

- 默认只输出西语正文。
- 不追加原始链接页脚，除非用户明确要求。
- 标题和正文必须拆分为独立标签。
- 不引入外部 JS/CSS/CDN。
- iframe 展示线上协议链接时，不强依赖注入 iframe 内部样式；跨域线上链接在本地开发环境会被浏览器拦截，只控制 iframe 外层容器、标题和 Tab UI。
